Create: git branch feature/menu
Switch: git switch feature/menu
Delete: git branch -d feature/menu
    Remote: git push origin --delete MarekMod

First push branch to origin(git repo), -u only for the first time(tracking reletionship): git push -u origin feature/player-movement
    After that: git push
See branches: git branch (-a -> all, -r -> remote,   -> lexotocal)
    See graph: git log --oneline --graph --all



git status	Shows staged/unstaged changes	You’ll run this constantly
git diff	Shows what changed since last commit	Helps write meaningful commits
git stash	Temporarily saves unfinished work	Great when you need to switch branches quickly
git restore	Undo changes in files	Safer than deleting manually
git reset	Unstage or move HEAD	Powerful for fixing mistakes
git revert	Undo a specific commit safely	Keeps history clean
git log -p	View commits + diffs	Good for debugging who changed what

git merge (name of the branch to merge into current)


rebase  Change the commit from which the branch splitted(from older version of dev to new version of dev)
